#PART 3

 1. SEO stands for Search Engine Optimisation. It involves improving a website so that it can appear higher in search engine results, such as Google. The main purpose is to make it easier for people to find a website online.
 2. SEO practices can improve user experience (UX) and website performanSEO helps improve the user experience by making websites easier to navigate, faster to load and suitable for different devices. It also helps users find the information they are looking for without struggling.
3. Implementing SEO helps a website attract more visitors and become easier to find online. It can also help a business reach more customers, build trust and promote its products or services.
 4. SEO techniques include using proper headings, descriptive page titles, relevant keywords and alternative text for images in HTML. CSS helps make a website responsive, while JavaScript should be used carefully so that important content can still be accessed by search engines.
 5. Meta elements are added inside the HTML head section to provide information about a webpage. They help search engines understand what the page is about and help browsers display it correctly on different devices.
Examples:
<title>NkatekoWears | Traditional Xitsonga Clothing</title>
<meta name="description" content="Explore beautiful traditional Xitsonga clothing at NkatekoWears.">
<meta name="keywords" content="Traditional clothing, Xitsonga fashion, African wear">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
