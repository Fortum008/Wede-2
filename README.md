## 3. What I Implemented for Part 2
**2.1 External Stylesheet:** Created `style.css` with consistent naming
**2.2 Base Style:** Set font-family, font-size, colour scheme, CSS reset for consistency
**2.3 Typography:** Used font-family, font-size, line-height, letter-spacing
**2.4 Layout:** Used Flexbox and Grid, with `display`, `flex-direction`, `justify-content`, `grid-template-areas`
